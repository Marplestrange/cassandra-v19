# Code de conduite

Ce dépôt est un lieu de travail : on y discute de code, de décisions et de défauts. Pour que chacun puisse y contribuer sereinement :

- **Parlez du travail, pas de la personne.** Une critique vise un choix, un code, une décision, jamais celui ou celle qui l'a fait.
- **Soyez précis et patients.** Un défaut bien décrit (version, étapes, ce qu'on attendait) se corrige vite ; une question de débutant mérite une réponse, pas un soupir.
- **Pas de harcèlement, d'insultes, de propos discriminatoires** (origine, genre, orientation, handicap, âge, religion, opinions), ni d'attaque répétée après un « non ».
- **Ne publiez rien de privé** : ni données personnelles d'autrui, ni secrets, ni adresses réelles de serveurs, les vôtres comme celles des autres.
- **La langue du projet est le français**, l'anglais est bienvenu : personne n'est moqué pour son orthographe.

## Ce qui arrive en cas d'écart

Les mainteneurs peuvent modifier ou masquer un commentaire, fermer une discussion, refuser une contribution, et écarter durablement quelqu'un qui enfreint ces règles.
On prévient d'abord quand l'écart est mince ; on ne prévient pas quand il est grave.

## Signaler un problème

Écrivez en privé à **marplestrange@cassandra.center** (objet : « code de conduite »). Le message reste confidentiel, y compris vis-à-vis de la personne visée tant que vous le souhaitez.
Une faille de sécurité ne se signale pas ici : voir [`SECURITY.md`](SECURITY.md).
