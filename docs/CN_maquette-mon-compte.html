Dans la base : une table-fiche aux noms de Dolibarr

Proposition. comptes reste étroite (identifiant, empreinte du mot de passe, type, société) ; la fiche vit à côté, colonne pour colonne comme llx_user. Les 6 anciens champs restent lisibles : display_name est dérivé.

CREATE TABLE comptes_fiche(
  compte TEXT PRIMARY KEY REFERENCES comptes(compte),
  civility_code TEXT, gender TEXT, lastname TEXT, firstname TEXT, birth TEXT,   -- ISO 8601
  job TEXT, employee INTEGER, ref_employee TEXT,
  dateemployment TEXT, dateemploymentend TEXT,
  email TEXT, personal_email TEXT, office_phone TEXT, office_fax TEXT,
  user_mobile TEXT, personal_mobile TEXT,
  address TEXT, zip TEXT, town TEXT, country_code TEXT, state_code TEXT,        -- ISO, pas les id Dolibarr
  photo TEXT, photo_source TEXT,   -- 'cassandra' | 'dolibarr' | 'fastpanel' | 'initiales'
  lang TEXT, color TEXT, signature TEXT,
  socialnetworks TEXT,                                                           -- JSON, comme Dolibarr
  note_public TEXT,
  id_doli INTEGER, doli_empreinte TEXT, doli_maj REAL, maj REAL NOT NULL);
Pourquoi une table à part : comptes_corbeille et le rejeu copient la ligne entière ; y mettre 25 colonnes d'état civil mélange l'authentification et l'identité.
→
Pourquoi ces noms : copier un champ vers Dolibarr ou en reprendre un n'est plus une traduction, juste une lecture de clé.
country_code et state_code en ISO
→
Dolibarr stocke un country_id propre à chaque instance ; on traduit à la frontière par son dictionnaire.
doli_empreinte
→
Empreinte des valeurs au dernier échange : permet de dire « qui a changé quoi » dans « Comparer », sans écraser.

Règle de la refonte : le module déclare, le noyau affiche

Le foyer d'un réglage dépend de sa portée, pas du module qui l'a créé. Le module garde un bouton de raccourci qui ouvre la carte, jamais une copie du formulaire.

PortéeQui la voitFoyer uniqueExemples
compteMoi seulMon compte › Branchementsboîte mail, CalDAV, Telegram, voix, préférences Itare
sociétéAdmins de la sociétéSociété › Réglagescanaux partagés, signature, fuseau de la société
globalAdministrateursParamètres générauxmaintenance, jetons du robot, modèles et plafonds, pare-feu
techniqueAdmin du moduleL'écran du module lui-mêmeseuils, moteur, paramètres qui n'ont de sens qu'avec ses données
